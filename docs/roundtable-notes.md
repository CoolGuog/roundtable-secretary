# 圆桌备注与改期备注

圆桌详情底部使用“备注与时间修改记录”入口，替代原来的复盘入口。原复盘记录与接口保留，不删除已有数据。

- 圆桌备注：成员补充集合地点、材料等说明，作者和时间由后台记录。当前成员可查看；关闭圆桌后只读。每条最多 500 字，每个圆桌最多 100 条。
- 改期备注：在手动选时区域选填，与时间方案一起保存。建议时间仍需所有成员重新接受后才生效，填写备注不会代替确认。
- 时间记录：显示最近 100 次方案的时间、备注和状态。“已确认”表示曾生效，之后可能再次改期。旧方案没有备注时显示“未填写备注”。
- 普通备注不会让正在等待确认的方案失效。秘书自动生成的方案只使用通用公开备注，不把个人偏好或私有推理写入共享记录。

## 验收

1. A 打开圆桌底部备注入口，添加集合地点；B 刷新后能看到作者、时间和内容。
2. A 手动改期并填写备注；B 在方案卡和时间记录中查看备注，确认前日程不变。
3. 全员接受后，记录变为已确认，原活动日程更新。
4. 再次改期，前一次时间和备注仍保留；长列表在框内滚动。

本机后台支持完整备注和时间历史；纯本机演示模式只保存普通备注，不模拟多人改期历史。
