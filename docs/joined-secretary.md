# 加入圆桌即参与秘书协商

创建或加入圆桌后自动启用忙闲计算，个人秘书可使用相关日期的日程名称、时间及偏好，通过后台已配置模型协商。创建/加入页面说明这一用途，不再逐项弹出授权步骤。

原始日程和偏好只用于本人的秘书上下文，共享过程不公开原文。退出、移除成员及关闭圆桌会使旧协商失效。最终时间方案仍必须全员接受才能写入日程。

默认参与状态在后台重启后按成员关系恢复；旧版授权接口为兼容保留，但新版页面不显示。明确调用旧版撤回接口仍会停止当前协商，不会在同一运行期自动覆盖撤回。

迁移会启用现有未关闭圆桌的忙闲参与，并增加圆桌版本，使迁移前的待确认方案失效。已确认写入的日程保留，用户重新发起协商即可。
