## 个人日程编辑（第二轮）

- 新增 `PUT /me/arrangements/:id`：替换一条安排，也接受只传部分字段，未传的字段保持原值。
  用 PUT 而非 PATCH，因为微信小程序的 `wx.request` 不支持 PATCH 方法。
- 越权（改别人的安排）与不存在的 id 一律返回 404，不泄露记录是否存在。
- 空 body、不支持的字段、非法日期、结束早于开始均返回 400，且不会改动原记录。
- 日程页每条安排新增"编辑"按钮，内联表单复用新增时的字段与校验，保存后刷新列表。

## 北京时间规则

- 后端换算集中在 `apps/api/src/time.ts`，小程序 `today()` 同样按 UTC+8 取"今天"，
  不再依赖设备本地时区。中国全境无夏令时，固定 +8 小时偏移是安全的。
- 数据库仍保存绝对时间（`timestamptz`），只在输入输出时换算；
  例如北京时间 2026-10-01 00:15 落库为 `2026-09-30T16:15:00Z`。

## 提交与恢复

本阶段保存在独立功能分支，通过 PR 审查后合并。保留提交历史；需要撤销时使用 `git revert`，或从已知检查点建立新分支。不要强制重写共享分支。

源码回退不等于数据库回退。不要通过重置数据库来恢复代码，后续迁移应尽量保持向前兼容，涉及现有数据前先备份。
