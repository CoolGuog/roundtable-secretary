# 本机秘书对话与草稿

2026-10-03。按当前开发方向，暂缓服务器购买与部署，先完善无需服务器的小程序功能。

## 使用方法

保持 config.ts 的 `mode: 'local'`，构建后打开秘书页即可使用。本机规则秘书不请求后台或模型，不需要 AppSecret；页面明确说明它不是 AI 聊天。

可以分步输入：`和导师开会` → `明天` → `下午三点` → `持续一小时`。秘书逐步追问缺少的信息，形成明天 15:00—16:00 的待确认草稿。核对或修改下方表单，点击 **确认保存**，才会写入本机日程。

也可以一次说完整：`明天下午三点到四点和导师开会`。输入 `改到后天下午五点` 会保留名称，修改日期和开始时间，再询问结束时间；`标题改为项目讨论` 只更改标题。手动改过的表单字段会作为下一轮补充的上下文。

## 规则和限制

- 日期支持今天、明天、后天、大后天、本周/下周/下下周、明确年月日和中文月日，按北京时间解释。过去的日期和不存在的日期需要重新确认。
- 支持 15:00、下午三点、半点等。中文 1—12 点未说明上午/下午时会追问；结束时间不默认一小时。
- 时长支持小时、分钟和半小时。结束不晚于开始、无效时刻、跨日时长不会形成完整可保存草稿。
- 每条安排最多 6 轮，达到上限可直接改表单或开始新安排。固定高度的对话窗口滚动显示最新回复。
- 对话只在当前页面内存中，不保存聊天历史，不发送个人记忆；切换标签可能保留页面，重启小程序或开始新安排会清空对话。已保存日程不受影响。
- 补充失败保留上轮字段和当前输入；离页、重开或卸载后的旧草稿结果不能覆盖新内容。
- 复杂自然语言、相对时间改动、多活动输入、自动考虑个人记忆尚不支持。不能识别时通过表单补充，保存前始终核对字段。

这是单设备本机演示，不具备真实多用户身份。后台 API 模式保持现有单轮模型草稿，本轮没有增加模型密钥输入框、后台多轮对话或服务器部署。
