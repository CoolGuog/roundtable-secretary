# 微信登录接入

已实现微信 code 换取自建会话、数据库用户绑定、小程序登录与重新登录、退出登录。默认仍为 local 页面模式和 demo 后台身份，真实微信换码需要配置对应小程序凭证。

## 开启方式

1. 小程序管理员在微信公众平台将调试账号添加为开发者。开发者工具项目 AppID 必须与后台配置一致；游客 AppID 不能验证真实登录。
2. 在后台本机 `.env` 中配置以下项目。AppSecret 仅存于后台配置，不发给前端，不提交 Git。

```dotenv
HOST=127.0.0.1
PORT=3000
STORAGE_MODE=postgres
AUTH_MODE=wechat
DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:5432/roundtable_dev?schema=public
WECHAT_APP_ID=wx0123456789abcdef
WECHAT_APP_SECRET=在本机填写实际值
```

3. 备份已有开发数据库，执行 `npm run db:deploy`、`npm run check`、`npm run start:api`。
4. 在 `apps/miniprogram/src/services/config.ts` 中设置 `mode: 'api'`、`authMode: 'wechat'`，填写本机后台 `apiBase`，执行 `npm run build:mini` 后重新编译。
5. 在“我的”页面点击微信登录，或访问日程触发登录。两个真实测试账号分别新增虚构日程，验证隔离、重启、退出和重新登录。

当前后台只监听本机，拒绝 production 模式。手机上的 127.0.0.1 不代表开发电脑；真机和公网部署仍需 HTTPS 域名、网络与完整生产配置。

## 接口与会话

| 接口 | 用途 | 约束 |
|---|---|---|
| POST /auth/wechat | 请求体仅为 `{"code":"wx.login 返回值"}` | 微信模式开放；不接受用户 ID 或 OpenID |
| GET /me | 当前用户展示信息 | 不返回 OpenID、session_key 或 AppSecret |
| DELETE /me/session | 退出当前会话 | 令牌即时撤销，不删除用户和日程 |
| /me/arrangements | 日程新增、列表、编辑和删除 | 所属用户始终来自后台会话 |

微信会话有效期 7 天，每个用户最多保留 5 个有效会话。数据库仅保存自建令牌 SHA-256 摘要。AppID 与 OpenID 联合确定用户，避免不同小程序串号。微信模式的 `/dev/sessions` 返回 404，不接受演示令牌。

客户端并发请求共用一次登录。读取遇到 401 后重新登录并最多重试一次；写入失败不自动重放。退出期间迟到的登录响应不能再次写入本地令牌。旧版演示缓存和演示日程不会自动归属给真实用户。

## 迁移与恢复

迁移 `20260929010000_wechat_sessions` 为用户增加 AppID，将 OpenID 唯一索引改为 AppID 与 OpenID 联合索引，新增微信会话表。保留现有用户、日程和演示会话，不重置数据库。

回退代码时可使用 `AUTH_MODE=demo`。不要为回退源码删除用户数据或执行数据库 reset；数据库恢复先在新建的本机数据库验证备份。
