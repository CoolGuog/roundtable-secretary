# 本机数据备份与恢复

更新：2026-10-15。本功能无需服务器，入口为「我的 → 备份与恢复本机记录」。

## 保存备份

点击「生成当前数据备份」，检查六类记录数量：单次日程、偏好与记忆、圆桌、会议复盘、会议工作台、重复日程规则。工作台按整份计数，内部包含任务、操作历史、会前清单和纪要版本。重复日程按规则组计数，包含每日／每周规则、截止日期、单次调课、跳过记录和后续分拆，不把展开后的每次课程另存为单次日程。

点击「保存备份文件（微信选择器）」打开微信的文件转存选择器，自行选定保存位置。只有主动操作才会打开选择器；小程序不会自动发送文件。开发者工具可能不支持原生转存，可在支持的微信环境操作。小型备份也可点击「复制备份文本」，粘贴到自己的文件中保存。

文件是明文 JSON，不包含会话、登录凭证、AppSecret 或服务器记录。请自行保管；只在小程序内生成的文件仍可能随缓存丢失，必须保存到外部位置。每次重新生成会更新小程序内同一个临时备份文件，已经转存到外部的旧文件不受影响。

页面时间按北京时间显示；文件中保留标准 ISO 时间。备份记录的是点击生成时的快照，后续修改需要重新生成备份。

## 检查并恢复

先导出一份当前记录。随后从微信文件中选择本应用生成的 JSON 备份，或粘贴完整备份文本并点击「检查并预览」。此时不写入记录。

预览显示每类将新增和跳过的份数，确认后才导入：

- 当前没有的编号：新增。
- 编号和内容相同：跳过，重复导入不会重复创建。
- 编号相同但内容不同：整次导入停止，保留当前修改；不自动覆盖、不按时间猜测哪个版本正确。需要查看旧版本时，可在独立空白演示环境恢复，先确保当前环境记录另有外部备份。

不合并同一工作台的部分任务或纪要；圆桌、复盘和工作台必须使用完整备份保持关联。未知格式版本、非法日期、无效比例、孤立记录、重复编号和超出容量均会被拒绝。本机复盘只能恢复草稿，不能导入伪造的全员共识，也不能替伙伴确认责任或任务。

预览后修改文本或离开页面，需要重新预览。如果本机记录在预览后发生变化，确认会停止并要求重新检查，避免沿用过时的结果。导入完成后返回对应页面，重新读取记录即可。

## 写入失败与恢复保护

正式写入前，先把原有六类记录保存为本机恢复日志。全部写入并清理日志后才显示成功。任一步骤失败会回退；发生进程中断或回退失败时，下一次访问本机业务记录会先重试恢复。恢复完成前停止继续修改，并提示释放设备空间后重试。升级前遗留的五类恢复日志也能处理，只回退日志中包含的记录，保留已有重复日程。

不要通过清缓存来处理恢复错误，否则可能一起删除恢复日志和原始记录。原生存储本身不可用时，不能保证立即回退，因此外部备份仍然必要。

本机日程读改写已调整为同步完成，避免日程保存与导入相邻发生时覆盖新恢复的记录。后台请求与身份流程保持原样。

## 容量和范围

- 单份业务数据最多 80 万字符；文件选择上限 320 万字节；文本粘贴和复制上限 6 万字符，大型备份用文件。
- 导入后仍遵守单次日程 100 条、重复日程 500 组（每组最多 500 条单次例外）、记忆 100 条、进行中圆桌 20 个、复盘和工作台各 100 份等原有业务配额。圆桌总记录最多支持备份 5,000 份，且受总字符限制。
- 恢复时需要额外存储空间保存原始日志；空间不足会拒绝或回退，不静默截断。
- 当前只支持本机模式；不包含后台数据库、真实多用户身份、设备自动同步、加密云备份或覆盖式还原。

## 新旧备份兼容（2026-10-15）

新版导出使用 version 2，新增 recurring 规则数组。version 1 的旧五类备份仍可恢复，其重复日程导入量为零，保留当前已有课程。旧版文件没有保存的课程无法从旧文件找回；请升级后重新生成并转存备份。新版文件需要在新版小程序中恢复，旧版小程序不支持 version 2。

单次例外必须属于对应规则的原始日期。单次调课可以移到规则日期范围以外，恢复后仍按调课后的日期显示。从第一次起取消或修改后续安排产生的空历史段也保留，避免将合法历史误判为损坏。清除本机演示数据会同时清除重复规则，请先转存备份。
